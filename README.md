## 📝 Starting from the Starter Project Angular-Post-List

* Add a `type` field to each post, using one of the following types: `news`, `politic`, or `education`.
* Modify the `posts.service` by creating an array of posts, a `get` method to retrieve the posts, and a method to update a post.
* Retrieve the posts using the Angular component lifecycle hook that you consider most appropriate.
* Create a custom reusable post component shared between the pages. The component should receive the post through **custom properties** and a button through **content projection** to deactivate the post on the Active Posts page and activate the post on the Inactive Posts page.
* Apply a different color to each post type using an Angular built-in directive: `news` → yellow, `politic` → black, and `education` → blue. Bootstrap classes can be used if desired.
